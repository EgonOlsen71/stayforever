# Stay Forever - Das Textadventure

Ein einfaches(?) Textadventure, inspiriert von den Stay Forever spielt-Folgen des <a href="https://www.stayforever.de/">Stay Forever-Podcasts</a>.

Die Story: Gunnar und Christian haben die Aufnahme einer neuen Folge für heute geplant, aber Christian ist nicht am Platz und auch nicht erreichbar. Das ist so ungewöhnlich, dass sich Gunnar auf den Weg nach Nürnberg machen will, um Christian zu finden.

Das Spiel ist für den C64 geschrieben worden. Ein Diskimage findet sich im Order "build". Eine Python-Version findet sich im Ordner "python". Diese ist das C64-Original kompiliert nach Python, sie "leidet" also unter denselben technischen Einschränkungen (40 Zeichen, keine Umlaute...).
Die Python-Version muss zusammen mit den Dateien aus dem "seq"-Ordner in einen Ordner kopiert und von dort gestartet werden.

Im Order "mega65" befindet sich noch ein Image mit einer Version für den MEGA65.
